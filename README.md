# Las Muñequitas

Videojuego arcade de avance lateral hecho con HTML5 Canvas y JavaScript puro (sin librerías ni imágenes externas).

## Cómo ejecutarlo
Abre `index.html` en el navegador (doble clic). No necesita servidor.

## Estructura
- `index.html` — página y lienzo del juego
- `css/style.css` — estilos y botones táctiles
- `js/game.js` — toda la lógica, el arte (dibujado por código) y los sonidos (Web Audio)
- `img/favicon.svg` — ícono de la pestaña

## Controles
- Mover: ← → o A D · Saltar: Espacio, ↑ o W · Disparar: X, J o F
- Pausa: P · Sonido: M · ENTER inicia, reinicia y activa pantalla completa
- Celular: botones en pantalla

## Niveles
- 1–5 Bosque post apocalíptico (jefe final: GLORIA)
- 6–10 Invierno post apocalíptico (jefe final: NISS)
- 11–15 Infierno (jefe final: El Diablito)
- Los demás niveles terminan con un mini jefe.

## Créditos
Idea, código, arte y sonidos generados con IA (Claude). No usa assets de terceros. Clasificación: ESRB E / PEGI 3.

## Publicar
Sube la carpeta completa a GitHub Pages, Netlify o itch.io (como proyecto HTML).
